# SimRoom

A full-screen home screen for a golf simulator room. The PC boots into big tiles;
anyone taps one and the right programs start. One key brings the home screen back.

Everything about the room (name, look, tiles, folders, displays, hotkeys) is data in
`%APPDATA%\SimRoom\room.json`, plus your images in `%APPDATA%\SimRoom\assets\`.
See [docs/room-json.md](docs/room-json.md).

> Status: **Phase 1 (skeleton)**. The home screen, folders, themes, clock, live
> reload of `room.json`, and the installer work. Launching, the editor, multi-monitor
> and the idle screen come in Phases 2–5. A full "new sim PC in 10 minutes" guide
> arrives with Phase 5. See [TESTING.md](TESTING.md) for what to check now.

## Run from source (Windows 11)

```powershell
# needs Node.js 22 LTS or newer
npm install
npm start                # full screen
npm run start:windowed   # in a normal window, handy while tinkering
```

## Build the installer

```powershell
npm run dist
```

This writes to `dist\`:

- `SimRoom-Setup-<version>.exe`: installer (per-user, with Start Menu and Desktop shortcuts)
- `SimRoom-Portable-<version>.exe`: single file, no install

## Project layout

```
package.json              name, version, productName, build settings
schema/room.schema.json   the room.json schema (validated on every load and save)
docs/room-json.md         human guide to every setting
src/main/                 Electron main process
  main.js                 window, simroom:// asset protocol, IPC, live reload
  store.js                load, validate, back up and save room.json (no Electron deps)
  preload.js              the small API the home screen is allowed to call
  default-room.json       the sample room written on first run
src/renderer/             the home screen (plain HTML/CSS/JS modules)
  app.js                  rendering, folders, navigation, clock
  themes.js               the six built-in theme presets
  styles.css
  fonts/                  bundled fonts (SIL OFL), generated by `npm run vendor`
  vendor/icons.js         built-in icon set (Tabler, MIT), generated by `npm run vendor`
build/icon.svg|png        app icon (`npm run icon` regenerates the PNG)
scripts/                  vendor-assets, make-icon, check-room, contrast
```

## Renaming the product

`SimRoom` is a working name. To rename it, change `productName` in `package.json`
(both the top-level field and `build.productName`). The window title, installer
name and data folder (`%APPDATA%\<productName>\`) all follow it.

## Useful scripts

| Command | What it does |
|---|---|
| `npm run check -- path\to\room.json` | Validates a room file and prints friendly errors. |
| `npm run contrast` | Checks every theme preset for readable contrast. |
| `npm run vendor` | Re-copies the icons and fonts from `node_modules` after changing the lists. |

Command-line options: `--windowed` (normal window) and `--data-dir=<folder>`
(use a different room folder, e.g. to try a room without touching the real one).
